ProjetoAPI / Repositório no Github: Trabalho-Final-BackEnd
Esta aplicação é uma integração Full Stack entre Front e Back-End para gerenciamento e controle de estoque e usuários usando banco de dados MySQL.

Tecnologias Utilizadas
Java, JavaScript, HTML/CSS, MySQL, Spring Web, Spring Boot, Spring Data JPA

Como executar a aplicação:
Fazer um git clone localmente com a seguinte URL: git clone https://github.com/gutoCodeC/Trabalho-Final-BackEnd.git
Importe o projeto para a IDE que irá utilizar como projeto Maven.
Configurar o Banco de dados local SQL de acordo com a seção abaixo.
Executar a aplicação em ProjetoApiApplication.java
Confirmar se a página está disponível em http://localhost:3606
Configuração do banco de dados:
A conexão com o banco de dados é gerenciada pelo arquivo de propriedades localizado em src/main/resources/application.properties

url=localhost:3306/projetoapi username=root password=123
